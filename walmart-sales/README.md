# Walmart 周销售额预测（PyTorch 线性回归）

根据门店、节假日、温度、油价、CPI、失业率等信息，预测 Walmart 某门店当周的销售额。

数据：Kaggle [Walmart Sales](https://www.kaggle.com/datasets/mikhail1681/walmart-sales)（45 家门店、2010–2012 共 6435 条周记录）。

## 结果

| 数据集 | MAE（美元） | RMSE（美元） | R² |
|---|---|---|---|
| 训练集 | 91,293 | 157,299 | 0.921 |
| 验证集 | 93,314 | 167,356 | 0.920 |
| **测试集** | **91,276** | **159,610** | **0.921** |

> 测试集 R² = 0.921；平均预测误差约 9.1 万美元（周销售额量级为 20 万～380 万美元）。

## 关键发现

- **门店是最强的决定因素**：45 家门店的固定效应解释了绝大部分销售额差异（仅 5 个外部因素时 R² 只有 0.02）。
- 其余因素（标准化后权重）：
  - **节假日 +**：节假日周销售额约 +7.5 万美元；
  - **CPI +**：物价水平越高，名义销售额越高；
  - **失业率 −**：失业率越高，销售额越低；
  - **油价 −、温度 −**：均为负向影响。

## 流水线

1. 读数据 → 2. 探索性分析（销售额分布 / 节假日对比 / 月度趋势）
3. 特征工程：门店 one-hot + 节假日 + 温度 + 油价 + CPI + 失业率
4. 划分训练 / 验证 / 测试 = 60 / 20 / 20
5. 标准化（数值特征与目标都只在训练集 fit）
6. 转 PyTorch 张量 → 7. `nn.Linear(49, 1)` + MSE + Adam
8. 训练 600 轮并跟踪最佳验证集 → 评估 MAE / RMSE / R² + 特征权重
